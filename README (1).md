# الدرس الأول التفاعلي: مفاهيم أساسية وتقديم البرمجيات الإحصائية

مقياس **البرمجيات الإحصائية المفتوحة** — جامعة وهران 2 — قسم العلوم الاقتصادية — 2025/2026
الأستاذ: ناشي سفيان

تطبيق [Streamlit](https://streamlit.io) لتقديم الدرس بشكل تفاعلي (واجهة عربية من اليمين إلى اليسار).

## المحتوى

| المحور | التجارب التفاعلية |
|---|---|
| المجتمع الإحصائي | سحب عيّنة من 500 عامل ومقارنة متوسط العيّنة بمتوسط المجتمع + تمرين تصنيف |
| الإحصاء الوصفي والاستدلالي | مقاييس ومدرج تكراري، فترات الثقة بعدة عيّنات، اختبار فرضية t |
| مدخل للاقتصاد القياسي | الأهداف والمهام + تمرين ربط الحالات بالأهداف |
| النموذج القياسي | أثر الحد العشوائي، خطي/غير خطي، ساكن/حركي، مراحل البناء |
| البيانات | سلسلة زمنية (إفساد الترتيب)، مقطعية (الفرز)، مجمّعة مقابل بانل |
| البرمجيات وتلخيص البيانات | بطاقات البرمجيات، نفس المهمة بـ 6 لغات، تلخيص بيانات (أو رفع CSV) وتحليل التباين |
| اختبار ختامي | 10 أسئلة مع تصحيح وتعليل |

## التشغيل محلياً

```bash
git clone https://github.com/<اسم-المستخدم>/<اسم-المستودع>.git
cd <اسم-المستودع>
python -m venv .venv
source .venv/bin/activate        # على ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## النشر على GitHub ثم Streamlit Community Cloud (مجاني)

1. أنشئ مستودعاً جديداً على GitHub (عام Public) باسم مثل `stat-lesson1`.
2. ارفع الملفات: `app.py` و`requirements.txt` و`README.md` والمجلد `.streamlit/`.
   ```bash
   git init
   git add .
   git commit -m "الدرس الأول التفاعلي"
   git branch -M main
   git remote add origin https://github.com/<اسم-المستخدم>/stat-lesson1.git
   git push -u origin main
   ```
3. ادخل إلى <https://share.streamlit.io> وسجّل بحساب GitHub.
4. اضغط **Create app** ← اختر المستودع والفرع `main` والملف الرئيسي `app.py` ← **Deploy**.
5. تحصل على رابط عام تشاركه مع الطلبة.

## التخصيص

- **بيانات الأستاذ والجامعة**: القاموس `COURSE` في أعلى `app.py`.
- **الألوان**: المتغيرات `PETROL` و`AMBER` و`INK`... و`.streamlit/config.toml`.
- **الاختبار الختامي**: القائمة `QUIZ` (السؤال، الخيارات، رقم الجواب الصحيح، التعليل).
- **مراحل بناء النموذج**: القائمة `stages` في الدالة `page_model`.
- **إضافة درس جديد**: انسخ المشروع وأضف دوال صفحات جديدة إلى القاموس `PAGES`.
